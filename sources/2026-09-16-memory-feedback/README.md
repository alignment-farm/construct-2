# What feedback makes experience worth retaining?

16 September 2026. Focused follow-up of existing leads while the user reports
maintenance-decision-transfer underway. No unpublished ancillary evidence was
inspected. This is selected primary-method reading, not new broad discovery.

**P48 — [Grounding Agent Memory, 2609.11060v1](https://arxiv.org/html/2609.11060v1).**
Previously an abstract lead in the adaptation-decision ledger; now inspected §3
and Appendix D's curation prompts. The curator receives completed trajectories,
terminal grades and existing memories. Its probing variant additionally checks
claims and scope through read-only environment tools before writing. Executor
and curator parameters remain fixed; explicit records persist across fresh task
sessions. This supplies a concrete precedent for improving the evidence used
to form memories. It does not establish a learned policy for deciding which
verification to purchase. Results, full cost accounting and code were not audited
in this pass; no numerical performance claim is adopted.

**P44 — [Interactive Memory Learning, 2609.17088v1](https://arxiv.org/html/2609.17088v1).**
Revisited §§3.3.2–3.3.5, especially Equation 2. Later response-quality reward is
credited to a stored fragment when it is triggered. This is a concrete learned
memory-policy signal, but not a counterfactual estimate of that fragment's causal
contribution. This does not imply that such credit cannot train a useful policy.
It motivates comparing feedback mechanisms by their later decisions, rather
than demanding perfect causal labels as an admission condition. Existing broader
reading remains in the adaptation-decision ledger.

These methods narrow the next root question: **when does outcome feedback teach
a useful memory decision, and when is additional evidence needed to distinguish
a valid lesson from a coincidental success?** Generic memory validation and delayed
memory-policy rewards already have implementations. Their comparative value for
the proposed question remains to be assessed; no novelty claim follows.
