## What the public release supplies

The [ModularRSI release](https://github.com/IQuestLab/ModularRSI/tree/b5c72c36b0d08ff93f00ee202a8fbdebe849dfb9)
contains a module archive and evaluation artifacts. Static composition falls
back to baseline modules; dynamic selection filters excluded variants. Its code
attributes one quarantine to a held-out benchmark regression. The released
traces describe final-harness evaluations, with model identifiers and cost
fields removed. These are useful implementation leads, not a matched dataset
of alternative interventions across identified recipients. Root inspected
configuration, source excerpts and one summary, without replaying scores or
validating the stated regression. Research contributions carry CC BY-NC 4.0;
Harbor-derived and third-party components have separate notices.

**Selection consequence:** develop an explicit account of which outcomes were
available when decisions were acquired. Published evaluation cases and their
release-informed exclusions cannot be treated as untouched confirmation for a
claim developed from them. A module appearing in an archive also does not prove
it is eligible, invoked or effective for the new recipient. Those are concrete
feasibility questions for the ancillary investigator. No wholesale adoption of
this platform or broad benchmark campaign is prescribed.

The inspected release does not settle whether decision experience transfers.
It reduces component-discovery work and clarifies the missing comparison. This
supports the bounded commission even though useful selector headroom and a
validated local workload remain unestablished.
