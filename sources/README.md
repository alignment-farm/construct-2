---

The existing sources already cover textual reflection, executable skill reuse,
evolving playbooks, neural memory, online updates, and training memory behavior. A
broad claim that agents can improve through persistent state would overlap heavily
with this work.

Our synthesis instead motivates questions about the conditions under which a
representation remains useful: access, transfer, correction, recurrence cost,
authority, and composition. These are directions to investigate, with novelty
still to be checked. The most useful next reading will inspect the closest methods
and ablations for a selected question, then widen the literature search where this
initial bibliography is thin.

## Research preference to date

Prioritize neural memory, live weight updates, and learned memory policies.
Voyager remains relevant background on system-level persistence, but executable
skill libraries are a lower-interest direction for this program. The question map
reflects this preference without treating it as an empirical verdict about
executable skills.
