## P98: SWE-Milestone

[2603.13428v4](https://arxiv.org/html/2603.13428v4), §§3–4, §5.1, limitations
and Appendix B.2. This resolves the earlier EvoClaw discovery lead at its current
title; no comparison of manuscript revisions was performed.

**Inspected:** reconstructed development dependencies, generated requirements,
persistent workspaces and isolated snapshot evaluation. The independent condition
uses canonical code. Construction filters for dependency-rich source changes and
uses human review. **Answers:** a public route beyond authored mini-projects
exists. **Narrows:** continuous-versus-independent results conflate history with
inherited code quality; they do not isolate extra memory. **Redirects:** retain
the matched-workspace diagnostic and consider an inspected real-history segment
for later confirmation. Headline performance was not reproduced.

## P99: SWE-Bench-CL

[2507.00014v1](https://arxiv.org/html/2507.00014v1), §§3.2, 5–6, 8–9.

**Inspected:** repository issue sequences, semantic retrieval and a workflow that
resets to each issue's base commit. Section 5 reports unreliable preliminary
evaluation; Section 8 describes proposed memory comparisons. Fine-tuning is a
suggested direction, not an established treatment result. **Answers:** issue-stream
memory comparisons are prior art. **Narrows:** ordered issues do not necessarily
inherit the agent's evolving program; proposed studies are not positive evidence.
**Redirects:** establish evaluator and participant competence before interpreting
memory effects. Code and data were not inspected.

## P100: Measure Before You Manage

[2608.31057v1](https://arxiv.org/html/2608.31057v1), §2, §§4.2–6.

**Inspected:** working-memory policy comparisons and retrospective accounting of
actual context, auxiliary calls and incomplete runs. The later retrieval comparison
lacks valid repair-success evaluation; its repeated-call endpoint can include
legitimate re-testing. **Answers:** nominally equal memory budgets need not imply
equal delivered context or total work. **Narrows:** process differences cannot
establish complete-task gains. **Redirects:** compare actual resource use and a
competent alternative use of the allowance, while keeping final behavior primary.
Its small, completion-conditioned results and unpinned served model do not provide
a reliable ranking for our study. No archived implementation or traces were replayed.
